# Академия Ибн Усаймина — платформа дистанционного обучения

Сайт-аналог [hdat.sa/Tases](https://hdat.sa/Tases) на русском языке: лендинг программы,
курсы с уроками, тесты с автопроверкой, еженедельные задания, итоговые оценки
(экзамен 70% + задания 25% + активность 5%, порог 60) и академическая выписка
вместо сертификата.

- **Стек:** Python 3.11+ · Django 5.2 LTS (поддержка до 2028) · PostgreSQL 16 (в разработке — SQLite) · свой CSS без сборщиков · vanilla JS без библиотек
- **Зависимостей всего 4:** Django, Pillow, python-dotenv, WhiteNoise (+ psycopg/gunicorn только на сервере)
- **Без внешних CDN:** шрифты, скрипты и графика лежат в `static/` — сайту нечему «отвалиться»

## Быстрый старт (Windows, Git Bash)

```bash
cd /e/Adobe/ibn-usaymin-academy

# 1. Виртуальное окружение (уже создано в .venv — при необходимости):
py -3.11 -m venv .venv

# 2. Зависимости:
.venv/Scripts/python.exe -m pip install -r requirements/dev.txt

# 3. Настройки: скопировать .env.example → .env и при желании поправить
cp .env.example .env

# 4. База + демо-данные + запуск:
.venv/Scripts/python.exe manage.py migrate
.venv/Scripts/python.exe manage.py seed_demo
.venv/Scripts/python.exe manage.py runserver
```

Открыть: **http://127.0.0.1:8000/** · админка **/admin/**

Демо-доступы (создаёт `seed_demo`):

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin@academy.local` | `admin12345` |
| Студент | `student@demo.local` | `student12345` |

> После входа в админку сразу смените пароль администратора!

WSL: то же самое, но `python3 -m venv .venv` и `.venv/bin/python`.

Внутри каждого модуля одинаковая раскладка (стандарт Django):

| Файл | Что в нём |
|---|---|
| `models.py` | данные (таблицы базы) — «что храним» |
| `views.py` | страницы и действия — «что видит пользователь» |
| `urls.py` | адреса модуля |
| `admin.py` | настройка админки для учителя |
| `forms.py` | формы ввода (если нужны) |
| `tests.py` | проверки логики |

## Модули: как отключить / добавить

Все модули перечислены в двух местах:

1. `config/settings/base.py` → список `LOCAL_APPS`
2. `config/urls.py` → строка `path(...)` модуля

**Отключить** модуль (например, библиотеку): удалить `"apps.library"` из `LOCAL_APPS`,
убрать строку `path("library/", ...)` из `config/urls.py`. Готово — сайт поднимется
без библиотеки, а блоки на главной/в навигации спрячутся сами (проверки
`apps.is_installed(...)` уже стоят).

**Включить обратно** — вернуть обе строки.

Зависимости между модулями:
- `core` нужен всем (не отключать);
- `grading` (кабинет и оценки) опирается на `courses` и после входа
  пользователь попадает в кабинет (`LOGIN_REDIRECT_URL` в `config/settings/base.py`);
- `exams` и `assignments` независимы, их видит `grading` через безопасные проверки.

## Учителю: ведение сайта без программирования

Всё через админку `/admin/` (вход администратором):

| Хочу… | Где |
|---|---|
| Добавить курс/урок | «Курсы и уроки» → Курс → добавить; уроки — прямо на странице курса (блок «Уроки»): видео-ссылка, аудио, PDF |
| Открыть курс свободно | Курс → галочка «Свободный доступ»: любой зарегистрированный проходит его без зачисления (статус «Слушатель») |
| Создать факультет | «Курсы и уроки» → Программа → добавить (например «Факультет акыды»); курсы привязываются к программе |
| Создать тест | «Тесты и экзамены» → добавить экзамен → вопросы внутри → у каждого вопроса варианты (отметьте галочкой правильные) |
| Вопрос с ручной проверкой | Тип вопроса — «Свободный ответ (проверяет учитель)»: студент пишет текст и/или крепит фото/аудио; проверка — в учительской |
| Проверить задания | Учительская `/teacher/` → «Проверить»: текст, фото-превью, аудио-плеер; баллы + комментарий |
| Оценить экзамен. ответы | Учительская `/teacher/` → «Оценить»: свободные ответы с файлами, баллы + комментарий |
| Поставить дедлайн заданию | «Задания» → задание → поле «Сдать до». Студент видит срок и бейдж «осталось N дней / меньше суток» |
| Отметить посещение | «Оценки и выписка» → «Посещение встреч» → добавить |
| Загрузить книгу в библиотеку | «Библиотека» → Материалы → добавить (укажите категорию и файл) |
| Выставить книгу | «Книги» → добавить, поле «Раздел»: продаётся (цена + кнопка заказа) / бесплатная (кнопка «Скачать») / онлайн («Читать») |
| Выставить счёт студенту | «Оплата обучения» → Счёт → добавить: за что, сумма; действием «Разбить на 2/3/4 части» — готовый график рассрочки |
| Отметить поступление | «Оплата обучения» → График платежей → выбрать строчки → «Отметить поступившим» |
| Реквизиты для оплат | «Ядро платформы» → «Контакты сайта» → «Реквизиты для оплаты» (видит только студент на своей странице платежей) |
| Проверить темы форума | Шапка сайта → «Модерация» (счётчик) или /forum/moderation/ — Одобрить / Удалить |
| Заблокировать нарушителя | Админка → Пользователи → выбрать → «Заблокирован до» + причина. Учиться может, публиковать на форуме — нет |
| Блок «Поддержать проект» | «Контакты сайта» → галочка + текст + реквизиты — появится в подвале |
| Спрятать раздел книг | «Ядро платформы» → «Контакты сайта» → снять галочку «Показывать раздел книг» |
| Новость / вопрос-ответ | «Новости и FAQ» |
| **Поменять название сайта** | «Ядро платформы» → «Контакты сайта» → «Название платформы». Применяется сразу, перезапуск не нужен. Запасной вариант — `SITE_NAME` в `.env` |
| Поменять телефон WhatsApp | «Ядро платформы» → «Контакты сайта» |
| Включить сдачу через мессенджеры | «Ядро платформы» → «Контакты сайта» → галочка «Показывать на заданиях отправку через WhatsApp/Telegram» — резервный канал на случай, когда сайт недоступен |

Экзамен проверяется **автоматически** (вопросы «один ответ» и «несколько ответов»;
в нескольких — засчитывается только полное совпадение). «Свободные ответы»
проверяет учитель вручную — итог попытки пересчитывается сам.

## Роли: админ и учителя

| Роль | Как назначить | Что может |
|---|---|---|
| Студент | регистрируется сам | учится, сдаёт, видит свои оценки и выписку |
| Учитель | админка → Пользователи → выбрать → группа «Учитель» (создаётся автоматически) | учительская `/teacher/` + весь контент в админке |
| Админ (персонал) | там же — галочка «персонал» | как учитель + управление пользователями и настройками |
| Суперпользователь | команда `createsuperuser` | вообще всё |

Ссылка «Учительская» с бейджем «сколько ждёт проверки» появляется в шапке
сайта сама — только у учителей и админов.

## Дизайн: две темы — отдельными файлами

Переключатель «Классика / Минимал» в шапке сайта.

- **paper (Классика)** — `static/css/themes/paper.css` — основная:
  слоновая кость + глубокий изумруд + золото, тёмная полоса hero,
  серифные заголовки, тёмно-зелёный подвал;
- **sand (Минимал)** — `static/css/themes/sand.css` — бежевый минимализм
  с арабской звездой, тонкие рамки, светлый подвал.

**Сделать другую тему основной** (показать учителю и сравнить):
1. на живом сайте — просто щёлкать «Классика / Минимал» в шапке;
2. для всех сразу, без кода — `.env` → `SITE_THEME_DEFAULT=sand`;
3. файлом — поменять порядок/состав `@import` в `static/css/tokens.css`
   (например, закомментировать одну строку).

Выбор посетителя хранится в cookie `theme` (год) — сервер сразу отдаёт
нужную тему, без мигания. Все цвета — переменными в файле темы:
поменять акцент или подвал = одна строка.

## Оплата и рассрочка (модуль payments)

Онлайн-кассы нет намеренно (договоры с платёжками — отдельный проект);
схема «выставил → перевёл → учитель подтвердил»:

- админ создаёт **счёт**: студенту, за что (поступление/обучение), сумма;
- действие **«Разбить на 2/3/4 части»** строит график рассрочки
  (равные части, шаг месяц, остаток — в первую);
- студент видит всё в «Кабинет → Платежи»: сумму, % оплачено, график
  со статусами (ожидает / просрочено / оплачено) и реквизиты;
- учитель отмечает поступление — часть становится «Оплачено».

## Свободные слушатели (не на основе)

Курс с галочкой «Свободный доступ» открыт любому зарегистрированному:
кнопка «Учиться свободно» записывает его со статусом «Слушатель».
Уроки, тесты и задания работают; в выписку слушатели не попадают.
В кабинете и профиле честный статус: **Студент / Свободный слушатель /
Пользователь (не на основе)**.

## Форум (модуль forum)

Разделы → темы → ответы. Статьи, вопросы, обсуждения:

- учителя и админы публикуют сразу; студенты и пользователи —
  **после модерации** (кнопка «Модерация» в шапке, со счётчиком);
- закрепление и закрытие тем, счётчик просмотров, аватары авторов;
- заблокированные (Пользователи → «Заблокирован до») не публикуют.

## Факультеты, дедлайны, профиль

- **Факультеты** = программы («Курсы и уроки» → Программа). Студент видит в
  кабинете карточку факультета: название и «обучение пройдено на N%» (средний
  прогресс курсов факультета), внутри — курсы с прогрессом уроков и баллами.
- **Дедлайны** — поле «Сдать до» у задания. В кабинете список «Задания к сдаче»
  показывает срок и остаток («осталось 2 дн.» / «меньше суток» — янтарным и
  красным), на странице задания — плашка срочности. После срока отправка
  закрывается.
- **Профиль** (`/accounts/profile/`) — аватар (до 2 МБ), имя, контакты и
  краткая сводка: программы, общий % и ближайший дедлайн. Полный прогресс —
  в кабинете.

## Деплой на сервер (кратко)

```bash
# на сервере (Ubuntu)
python3 -m venv .venv && .venv/bin/pip install -r requirements/prod.txt
cp .env.example .env && nano .env      # SECRET_KEY, DB_ENGINE=postgres, ALLOWED_HOSTS, почта
docker compose up -d                   # PostgreSQL
.venv/bin/python manage.py migrate
.venv/bin/python manage.py collectstatic --noinput
.venv/bin/python manage.py seed_demo   # один раз, для старта
.venv/bin/gunicorn config.wsgi --bind 127.0.0.1:8000
```

Nginx перед Gunicorn: готовый пример — `deploy/nginx.conf.example`
(скопировать в `/etc/nginx/sites-available/`, поменять домен и пути;
отдаёт `/media/` сам, остальное проксирует в Gunicorn). Статику
обслуживает WhiteNoise — отдельный сервер статики не нужен.

### Переменные окружения (.env)

| Переменная | Значение |
|---|---|
| `SECRET_KEY` | секретный ключ (генерация в комментарии .env.example) |
| `DEBUG` | только `True` на своём компьютере |
| `ALLOWED_HOSTS` | домены через запятую |
| `SITE_NAME` | название платформы |
| `SITE_THEME_DEFAULT` | тема по умолчанию: `paper` / `sand` |
| `DB_ENGINE` | `sqlite` (разработка) / `postgres` (прод) |
| `DB_*` | параметры PostgreSQL |
| `EMAIL_BACKEND` | `console` (разработка) / `smtp` + настройки почты |

## Почта: сброс и смена пароля

Сайт умеет две вещи: **сброс пароля по e-mail** («Забыли пароль?» на странице входа)
и **смену пароля** в профиле (без писем).

В разработке письма печатаются в консоль сервера. Для настоящей почты
заполните в `.env` (пример для Яндекса):

```
EMAIL_BACKEND=smtp
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_USE_SSL=True
EMAIL_HOST_USER=ваш-логин@yandex.ru
EMAIL_HOST_PASSWORD=пароль-приложения   # в Яндексе: Настройки → Безопасность → пароли приложений
DEFAULT_FROM_EMAIL=Академия Ибн Усаймина <ваш-логин@yandex.ru>
```

Проверка: `python manage.py check_email --to ваша@почта.уз` — придёт тестовое письмо.

## Онлайн-лекции (созвоны)

Учитель преподаёт вживую — расписание в разделе «Встречи»:

- Создать встречу: админка → «Онлайн-встречи» → тема, дата-время, длительность,
  **ссылка** (Zoom / Google Meet / YouTube-трансляция)
- Статус считается сам: «Запланирована» → «Идёт сейчас» → «Завершена»
- Ссылку подключения студент видит **за 15 минут до начала** и во время встречи
- Ближайшая встреча показывается студенту в кабинете
- Посещение для оценки (5%) учитель отмечает: админка → «Посещение встреч»

Уроки (заранее записанные) загружаются в админке на странице курса:
видео — ссылкой на YouTube/VK (сайт сам сделает плеер), аудио и PDF — файлами.

## Своя графика: что куда класть

Все картинки лежат в `static/img/`. Чтобы поставить свои:

| Файл | Что это | Рекомендация |
|---|---|---|
| `logo.svg` | логотип в шапке, футере и вкладка браузера | свой файл `logo.png` положить рядом и в `templates/base.html` заменить три упоминания `logo.svg` на `logo.png` (шапка, футер, favicon) |
| `ornament-pattern.svg` | фоновый узор «восьмиконечная звезда» (hero, выписка, кнопка-призыв) | заменить файл тем же именем — подхватится везде |
| `ornament-star.svg` | большой медальон в hero (тема «Минимал») | аналогично |
| `ornament-divider.svg` | разделитель на выписке | аналогично |

Эмодзи-иконки блока «Как устроено обучение» (📖 ✍️ 🎙️ ✅) — в файле
`templates/landing/home.html` (ищите `feat__ic`) — замените на `<img>`
со своей иконкой: `<img class="feat__img" src="{% static 'img/ваша1.png' %}" alt="">`.

Цвета сайта (акцент, золото, фон) — в начале `static/css/tokens.css`:
поменять 3–4 строки переменных в обеих темах.

## Резервные копии и обслуживание

```bash
python manage.py backup_db     # копия базы в backups/ (SQLite — сразу; Postgres — покажет команду pg_dump)
python manage.py test          # все проверки (25 шт.)
```

Ошибки сайта пишутся в `logs/django.log` (ротация раз в неделю, 8 копий).

## Безопасность (что уже встроено)

- Вход по e-mail с **защитой от подбора**: 8 неудачных попыток → блокировка на 15 минут
- CSRF-токены на всех формах; сессии и cookies — HttpOnly
- Загрузка файлов: **белый список расширений** (фото/аудио/PDF/документы) и лимит размера (100 МБ)
- Каждый студент видит **только свои** попытки, ответы и выписки (проверено тестами)
- Учительская — только для учителей/админов (группа «Учитель» создаётся автоматически)
- `SECRET_KEY` и пароли живут в `.env` (в git не попадает, `.gitignore` настроен)
- В продакшене: DEBUG=False, HSTS и Strict-Transport при HTTPS (`SITE_HTTPS=True`),
  X-Frame-Options DENY, nosniff, referrer-policy
- Пароли хранятся только в виде хэшей (алгоритм PBKDF2 Django)
